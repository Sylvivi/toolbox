# 书籍类型与社科「导读」

> 从 `CLAUDE.md` 拆出的功能笔记（2026-08-06 拆）。**动这块代码之前先整本读一遍**——里面每条 ⚠️ 都是踩过的坑。

- **书籍类型：小说 / 社科（2026-07-27 加）**：整个阅读体系原本**只为小说造**（全文 22 处「小说」硬编码：防剧透、伏笔、人物表、剧情摘要）。现在每本书带类型，`reading_book_kind = {"文件名|大小":"social"}`（照抄 `reading_book_titles` 那套：localStorage + `_ts` + **必须挂进 `cfBuildManifest`**，另加拉取端按 ts 覆盖 + 备份导入端），**默认（表里没记）＝小说**，书架 ⋯ 菜单「🎓 标为社科书」手动标。判定入口 `rbIsSocial(b)` / `rbCurBookIsSocial()`（阅读模式看 `readerBookId`、共读看 `rbGetConvBook()`）。**社科书的分岔点**：① 点段操作栏多「导读」键；② 人设换 `SOCIAL_MODE_PERSONA`（**刻意不读系统提示词框**——框里是读小说的蘑菇人设，含男生子题材声明 228 字 + 家族树画法 186 字，对社科书是噪音，且「像朋友唠嗑不是赏析课」跟"讲清楚"反着来）；③ 摘要/全书脉络改论点版；④ `readerUpdateMemoryTables` 直接 return false（没人物没伏笔）。改这块**务必同时改小说分支**、并跑回归确认小说路径一字未变。

- **社科书「导读」（2026-07-27 加）**：解决「读社科书要手打『请对以上做导读』+ 手打小标题当路标」。**小标题自动识别**：`rbLineIsHead(s,nxt)`（2~24字、不以句末标点收尾、非 ●列表/`a.`选项/图注、后面须跟 ≥40 字正文段）+ `rbDetectHeads(lines)` + `rbSectionOf(lines,pNum)`→`{headP,startP,endP,title}` + `rbSectionText`（`SECTION_CHAR_BUDGET=12000`，超了从**节尾往前**留）。在《社会性动物》9 章正文实测 **67 个小标题全中、零误判**。**生成走 `readingAskOne(msgIdx, pNum, '导读', bar, {guide:true})`**——第 5 参 `opts.guide` 是唯一新入口，函数内把「你点的段」扩成整节、**把 pNum 改写成 `sec.headP`**（于是流式锚点/落盘/`readingRerenderMsg` 全部自动挂到小标题后面＝插节首，重读时先看导读），其余流式气泡/停止键/`reader_qa` 同步/读痕**全部复用不另起一套**。用户定的形态：**只要人话讲解**（不加概念块/论证脉络块）、允许引书外例子和后文关联但以本节为主、**插节首不跳回**。测试 `sec.js`/`guide.js`/`regress.js`。
